##  Topics Covered

###  Search
Uninformed and informed search strategies to navigate problem spaces — from social networks to adversarial games.

###  Knowledge
Representing facts with propositional logic and writing AI agents that reason using inference rules.

###  Uncertainty
Probabilistic models including Bayesian networks and Markov chains to reason under incomplete information.

###  Optimization
Solving constraint satisfaction problems using arc-consistency and backtracking search.

###  Machine Learning
Supervised learning (k-NN), reinforcement learning (Q-learning), and evaluation with real-world datasets.

###  Natural Language Processing
Parsing sentences with context-free grammars and exploring transformer attention mechanisms.
